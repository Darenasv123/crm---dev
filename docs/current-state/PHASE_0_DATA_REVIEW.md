## Registros ZIP sospechosos identificados

La revisión detectó registros asociados con ejecuciones de prueba del importador
ZIP. Los identificadores concretos se omiten deliberadamente.

## Criterios seguros para distinguirlos

- origen técnico de importación compatible con una ejecución de prueba;
- correlación temporal con la ventana de validación;
- ausencia de actividad operativa posterior;
- revisión conjunta de cliente, expediente, documentos y Storage;
- aprobación manual antes de cualquier eliminación.

Una ruta o etiqueta de importación aislada no constituye evidencia suficiente
para eliminar datos.

## Acción tomada

Durante la fase documentada no se eliminaron ni corrigieron datos remotos. La
información quedó preparada para revisión manual mediante un procedimiento con
dry-run, respaldo y detención ante conflictos.
